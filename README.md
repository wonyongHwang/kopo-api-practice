# API Lab (Student Exercises)

7가지 API 유형별 최소 예제 모음입니다. 각 폴더의 README를 보고 실행하세요.

## 폴더 구성
- `01-rest-flask`: REST API (Flask)
- `02-soap-spyne`: SOAP API (Spyne)
- `03-grpc-python`: gRPC (Python)
- `04-graphql-graphene`: GraphQL (Flask + Graphene)
- `05-webhooks-flask`: WebHooks 수신 서버 (Flask)
- `06-websockets-socketio`: WebSockets (Flask-SocketIO)
- `07-webrtc-p2p`: WebRTC (브라우저) + 간단 시그널링 서버

## 공통 준비
- docker compose up -d
